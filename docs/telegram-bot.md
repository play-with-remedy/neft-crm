# Telegram-бот клуба

Бот в личном чате проверяет, занят ли игровой ник в клубе. Принимаются ники
на русском, с цифрами, пробелами и знаками препинания. Ник должен содержать
хотя бы одну русскую букву. Регистр букв и пробелы по краям не учитываются.
Данные карточки игрока не отправляются. Команды `/start` и `/help` показывают подсказку.

Создание игрока доступно только отправителю с Telegram username `DyrachyoGaming`.
Username берётся из `message.from` в защищённом webhook, сравнивается без учёта
регистра; ID отправителя должен совпадать с ID личного чата.
Username в пересланном сообщении или введённый текст не дают доступа.

После `/start` доступна кнопка «Добавить игрока»; также работает `/add`.
Бот запрашивает ник и явное подтверждение кнопкой «Сохранить». Перед сохранением
ник повторно проверяется на совпадение. Сохраняется только `nickname`;
дата первого посещения и остальные поля остаются незаполненными.
Кнопка «Отмена» или `/cancel` отменяет действие. Черновик действует 20 минут.

## Настройка

Добавить в `.env` сервера:

```dotenv
TELEGRAM_BOT_TOKEN=
TELEGRAM_WEBHOOK_SECRET=
TELEGRAM_PLAYER_CREATOR_USERNAME=DyrachyoGaming
```

Для `TELEGRAM_WEBHOOK_SECRET` использовать случайную строку, например 64 hex-символа.
Токен и секрет не добавлять в Git. Остальные настройки `.env` сервера сохраняются.

После выкладки файлов:

```bash
php artisan config:clear
php artisan route:clear
php artisan telegram:setup --url=https://mafmmt.by/telegram/webhook
```

Использовать установленный на сервере PHP версии 8.3 или новее.
Webhook принимает только POST с секретом в заголовке
`X-Telegram-Bot-Api-Secret-Token`. Проверка CSRF отключена только для этого маршрута.
Повторные доставки обработанного update не создают новых ответов в течение суток.
Ответ сохраняется до отправки в Telegram: при сетевой ошибке повторная доставка
не создаёт второго игрока и повторяет первоначальный ответ.
На каждый чат действует лимит 20 ответов в минуту.

## Проверка

```bash
php artisan test --compact --filter=TelegramWebhookTest
```

В Telegram открыть бота, отправить `/start`, существующий ник в другом регистре
и отсутствующий ник. Запрос к webhook без секрета должен вернуть 403.
