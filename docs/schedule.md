# Расписание клуба

Страница `/admin/schedule` находится в разделе «Клуб» и работает с таблицей
`evenings`. Созданный здесь вечер сразу доступен в общем разделе «Вечера»;
изменение или удаление записи отражается на обеих страницах.

Короткая форма расписания и полная форма вечера используют общие поля:
проект, тип, дату и время, адрес, стоимость в BYN. Для расписания проект и тип
обязательны. Адрес и стоимость необязательны; пустая стоимость означает
«Не указана», нулевая стоимость отображается как 0 BYN.
Изменение основных полей не меняет участников, оплаты, расходы и команду.
Права доступа и блокировки вечеров действуют и на странице расписания.

Даты `played_at` сохраняются как местные дата и время клуба (Europe/Minsk),
без изменения прежних дат. Глобальная временная зона приложения не меняется.
По умолчанию расписание показывает сегодняшний день и будущие даты;
фильтр периода позволяет открыть историю.

Статусы не добавляются. Вечер начинает учитываться в отчётах после наступления
его даты и времени. Позднее внесение участников и оплат обновляет показатели.
Стоимость из расписания не является выручкой: выручка считается по оплатам.

## Миграция

```bash
php artisan migrate --path=database/migrations/2026_11_21_120000_add_schedule_fields_to_evenings_table.php --force
php artisan filament:clear-cached-components
php artisan route:clear
php artisan view:cache
```

Перед применением миграции на существующей базе сделать полный бэкап.
Добавляются только nullable-поля `address` и `price`; существующие данные
и поле `played_at` не преобразуются.

## CSV

Экспорт включает адрес, стоимость и время. Вечер без участников, команды
и расходов выгружается отдельной строкой типа «Вечер». Старые CSV без
новых колонок импортируются; уже сохранённые адрес и стоимость не стираются.
